# Crypto Tracker Dashboard (`crypto-tracker-dashboard`)

A high-performance real-time cryptocurrency portfolio tracker and analytics dashboard built with modern Tailwind CSS and interactive SVG data visualizations.

## Features
- **Hero Stat Tiles**: Real-time overview of total portfolio valuation, 24h trading volume, active tokens, and market sentiment.
- **Interactive SVG Area Chart**: Tracks cumulative portfolio performance over a 7-day period with gradient fills and tooltips.
- **Trading Volume Bar Chart**: Visualizes daily transaction volume with interactive hover states.
- **Live Markets Table**: Real-time asset pricing, 24h percentage changes, and market capitalization for major tokens (BTC, ETH, SOL).
- **Architecture & System Design**: Fully documented with Mermaid diagrams (`docs/architecture.md`).

## Quick Start
Open `src/index.html` in any modern web browser or serve it locally using a static server.
